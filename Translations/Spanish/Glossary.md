# Ambermoon – Spanish glossary (draft)

Source language is the **German original** (DE); the English version (EN) is listed for
reference because the file structure of the Spanish release follows the English data.
Length limits are given in characters where the game imposes them (see `README.md`).

Status: **draft for review** – every entry may still change after native-speaker review.
