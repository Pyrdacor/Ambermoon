Ambermoon Tools

Editors for the game data of the Amiga game Ambermoon, running in your browser. Nothing is uploaded: the files you open stay on your computer, and what you save is downloaded.

Map Editor 2D

Edits the 2D maps: towns, indoor maps, dungeons and the world maps.

  • Tiles, events, map properties and tilesets
  • Monsters and NPCs with their paths over the day
  • Open the folder of the game data (Amberfiles) on a computer
Open the map editor

Image Editor

A paint program for PNG, BMP and the graphics of the game.

  • Bit planes with 1, 3, 4 or 5 bits per pixel, textures, frames
  • Containers (.amb), monsters, palettes of Palettes.amb
  • Selection, mirror, rotate, resize, animation preview
Open the image editor
  • The map editor needs a folder of the game data; browsers on phones cannot choose folders.
  • When the map editor saves, every changed file of the game data is downloaded: copy them back into the folder of the game data.
  • For the monsters of Monster_char.amb, choose Monster_gfx.amb and Palettes.amb together with it.
  • The tools are also available as programs for Windows, Linux and the Amiga: tool releases · source
